Publication trust file · fictional, static, and transparent by design

Authored data behavior

This site consists of static HTML, CSS, JavaScript, WebP images, a robots file, and a sitemap. Its authored code does not create accounts, submit forms, set analytics cookies, embed advertising, load third-party fonts, request location, or call a remote application service. The menu script runs locally in the browser and does not transmit a preference.

Hosting and network records

GitHub Pages and the networks used to reach it may process ordinary request information such as IP address, requested path, time, browser or device details, security signals, and service logs under their own terms and policies. This fictional publication does not control that infrastructure and makes no promise about records held by a browser, access provider, employer, or host.

External destination

The main feature contains one editorial link to a separately operated commerce article. The destination is not loaded until a reader follows the link, and the authored URL carries no campaign query parameters. Leaving Bracket & Bay means the other site’s current content, terms, and privacy practices apply. None of the guide or trust pages contains that external commerce link.

No correspondence database

The example email uses the reserved .example domain and is not monitored. There is no contact form, comment system, newsletter, checkout, support queue, or reader database behind these pages. Readers should not attempt to send personal or confidential information to a fictional identity.

Changes would require a new review

If a future operator adds analytics, forms, embedded video, social widgets, advertising, commerce, personalization, or any other remote dependency, this notice would no longer describe the site. A responsible launch would inventory recipients, purposes, retention, access, consent where applicable, and a real contact route before activating those features. This text is not a substitute for that review.

Public files and local evidence

The public manifest contains only the ten pages, local style and menu files, four editorial images, robots instructions, and the sitemap. Build scripts, source PNG files, screenshots, validation results, deployment credentials, and certification evidence stay outside the published repository tree. This separation reduces accidental disclosure of production material, but it does not create anonymity against hosting or network infrastructure.

The site does not use browser storage, service workers, fingerprinting code, cross-site embeds, or hidden tracking pixels. Ordinary browser features may still preserve history, cached files, bookmarks, downloads, or accessibility preferences on the reader’s device. Those local behaviors belong to the browser and device configuration rather than this authored publication. Readers using managed equipment should follow the privacy and retention guidance of the organization that controls it.
